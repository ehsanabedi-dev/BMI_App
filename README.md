# BMI Calculator (Flutter)

A practice project I built while learning Flutter: a simple **Body Mass Index calculator** with a clean dark UI.

> Built as part of my Flutter training. The app idea and layout follow a well-known Flutter course exercise; I used it to practise widgets, state and navigation.

## Features

- Select gender, height, weight and age
- Calculates BMI and shows the result category (Underweight / Normal / Overweight) with a short interpretation
- Reusable custom widgets and a separate calculation class (`CalculatorBrain`)
- Runs on Android, iOS and the web (PWA)

## What I practised

- Stateful widgets and `setState`
- Building reusable components
- Navigation between screens and passing data
- Separating UI from logic
- Theming and shared style constants

## Tech

Flutter · Dart · `font_awesome_flutter`

## Run locally

```bash
flutter pub get
flutter run
```
